# DisplayMixer

DisplayMixer 是一个 macOS 菜单栏工具，用来集中控制外接显示器和应用音频。

## 主要功能

- 通过 DDC/CI 调节外接显示器亮度。
- 通过 CoreAudio 调节默认显示器音频设备的音量和静音。
- 使用 F1/F2 调节亮度，使用 F10/F11/F12 调节静音和音量。
- 为正在播放声音的 App 提供独立音量控制。
- 支持实时拖动显示器亮度和音量滑块。
- 支持按键步进设置，以及仅用于音量的精细步进。
- 提供自定义调节浮层、开机自启、权限申请和显示器数值同步。

## 系统要求

- macOS 15.0 或更高版本。
- 外接显示器需要支持 DDC/CI。
- 使用键盘控制需要在“系统设置 → 隐私与安全性 → 辅助功能”中允许 DisplayMixer。
- 使用分应用音量需要在“系统设置 → 隐私与安全性 → 屏幕录制”中允许 DisplayMixer。
- 默认键盘设置下，DisplayMixer 使用媒体键事件控制 F1/F2 亮度；F3/F4 等功能键无需按住 Fn。

## 安装

打开 Releases 页面下载 `DisplayMixer-1.1.0.dmg`，将 DisplayMixer 拖入“应用程序”文件夹后运行。

首次运行后，从菜单栏图标进入权限申请和功能设置。

## 更新日志

### v1.1.0

相比 v1.0.0，v1.1.0 主要更新如下：

- 键盘亮度控制适配系统媒体键：使用默认键盘设置时，直接按 F1/F2 即可调节亮度，不需要在系统设置中开启“将 F1、F2 等键用作标准功能键”，也不需要按住 Fn。
- 多显示器键盘控制会优先操作鼠标所在的外接显示器，没有匹配到时再使用设置的主显示器。
- 亮度滑块在 75% 附近增加吸附效果，便于快速定位到 75% 的常用亮度。
- 重做亮度、音量和 App 音量滑块的视觉样式：使用自定义填充轨道、圆形旋钮和百分比显示，并让滑块宽度随菜单宽度自适应。
- 修复菜单刷新时自定义滑块可能显示为禁用状态的问题。
- 优化音量调节和取消静音流程，避免每次音量变化都重复发送静音指令，减少部分显示器硬件 OSD 闪烁。
- 优化媒体键监听和事件处理，使辅助功能权限变化时的事件放行更可靠。
- **精准步进仅控制音量，不控制亮度。** 开启“使用精细步数”后，音量会根据当前音量区间使用 1%、2%、5% 或 10% 的精细步长；亮度始终使用“按键步进”中选择的普通步长。

## 按键步进

在菜单栏的“按键步进”中可以选择普通步进。开启“使用精细步数”后，音量功能键会按照当前音量使用精细步进；亮度功能键不受此选项影响，始终使用用户选择的普通步进。按住 Shift+Option 再按音量功能键，则使用用户选择的普通步进。

精细步进规则如下：

- 0%-10%：1%
- 10%-30%：2%
- 30%-50%：5%
- 50%-75%：10%
- 75%以上：5%

## 权限说明

使用键盘控制需要在“系统设置 → 隐私与安全性 → 辅助功能”中允许 DisplayMixer；使用分应用音量需要授予屏幕录制权限。

## 构建

项目使用 Swift Package Manager 和 AppKit 构建。在项目目录执行：

```sh
./build-app.sh
./build-dmg.sh
```

`build-app.sh` 会构建、签名并安装到 `/Applications/DisplayMixer.app`。当前发布包使用 ad-hoc 签名，首次打开时可能需要在 Finder 中右键选择“打开”。
